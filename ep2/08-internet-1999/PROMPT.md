# The internet in 1999 (demo)

The exact one-shot prompt, as given to Claude Fable 5 — no follow-ups, no retries:

```
Build a playable version of the internet in 1999 — one runnable HTML file. It boots with a dial-up connection screen and modem sounds. A browser-in-browser surfing GeoCities-style pages: visitor counters, guestbooks, under-construction GIFs, webrings, a MIDI toggle. A working search engine that only returns results from that era. At least a dozen interlinked pages to get lost in.
```
