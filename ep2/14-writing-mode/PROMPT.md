# Writing Mode (build-on-established · the yoink)

The exact one-shot prompt, as given to Claude Fable 5 — no follow-ups, no retries:

```
Add a Writing Mode to my creator dashboard — and don't invent a new editor, yoink Google Docs. A toggle flips the card board into writing mode and the screen becomes Google Docs: white paper page, the toolbar, the ruler, the works. Every video is a tab in the left sidebar, like chapters. Click a video and its content doc loads ready to edit — no doc yet, blank page. Rich text (headings, bold, italic, lists, images), autosave on every keystroke, stored in my existing database. If you didn't know better, you'd swear you were in Google Docs — except every doc is one of my videos.
```
