The exact one-shot prompt, as given to Claude Fable 5 — no follow-ups, no retries:

```
Add a private "Testing Lab" to my creator dashboard — visible only to my admin email, invisible to every other user. A Kanban-style comparison board for AI model tests: each test is a row anchored by the exact prompt on the left, and each column to the right is a model run — Fable 5 today, Grok or whatever ships next month — holding result screenshots, model name, date, and a verdict. One click to add a new run to an existing test and compare side by side.
```
