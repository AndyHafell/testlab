# Cabin restoration game (demo)

The exact one-shot prompt, as given to Claude Fable 5 — no follow-ups, no retries:

```
Build a 3D restoration game in the browser — one runnable file. A cabin by the water, completely wrecked by rats and moles: patch the holes, fix the roof, repair it plank by plank. Beside it, an overgrown forest: clear it, dig swales into the terrain to catch water, plant a food forest, and grow the land toward self-sustaining. Two layers — fix the cabin, revive the land — with visible progress: the cabin gets cozier, the forest gets greener. Walk around in it.
```
