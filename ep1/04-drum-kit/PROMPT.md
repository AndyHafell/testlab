# Virtual drum kit (demo)

The exact one-shot prompt, as given to Claude Fable 5 — no follow-ups, no retries:

```
Build a playable virtual drum kit in the browser — one HTML file. Realistic pads (kick, snare, open and closed hi-hat, three toms, crash, ride) triggered by mouse click or keyboard keys, with each key labelled on the pad. Real drum sounds (synthesize them with the Web Audio API if there are no samples). A beat recorder: hit record, play a pattern, loop it back, with a tempo slider. A visual hit animation on each pad. Make it fun and instantly playable.
```
