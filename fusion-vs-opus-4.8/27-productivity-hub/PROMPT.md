# Productivity Hub (Kanban + calendar + to-do + Pomodoro)

The exact one-shot prompt, fired at both `openrouter/fusion` and `anthropic/claude-opus-4.8` — same prompt, no follow-ups, no retries:

```
Build me an all-in-one productivity app in the browser — one runnable HTML file, dark and sexy, the kind of thing I'd actually want to run all day to get stuff done. It should pull the core tools into one clean workspace: a Kanban board, a calendar, a to-do list, and a Pomodoro timer, switchable from a sidebar or tabs, all sharing the same tasks so it feels like one product, not four widgets bolted together.

Make each part real and usable. The Kanban board: columns like To Do / Doing / Done with cards I can add, edit, and drag between columns, with labels and maybe due dates. The calendar: a proper month view where tasks and events show up on their day, and I can click a day to add something. The to-do list: quick add, check off, reorder, with priorities. And a Pomodoro timer: 25/5 work-break cycles with start / pause / reset, a session counter, and a gentle chime when a block ends, ideally tied to whatever task I'm focused on.

Wire it together so it feels cohesive — a task I make in one place shows up in the others, and there's a little dashboard or home view with today's tasks, what's due, and my focus stats. Save everything to local storage so it survives a refresh. Lean into the design: dark, premium, smooth little animations, the kind of polished UI that makes you want to stay organized. One runnable HTML file.
```
