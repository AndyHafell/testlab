# Pixel Synth (FL Studio-style 8-bit looper)

The exact one-shot prompt, fired at both `openrouter/fusion` and `anthropic/claude-opus-4.8` — same prompt, no follow-ups, no retries:

```
Build me a FruityLoops-style music maker in the browser — one runnable HTML file, but the whole thing is a pixel synthesizer: 8-bit, chiptune, that gorgeous retro game-music feel, all synthesized in code with the Web Audio API (no sample files). Think a 16-step grid sequencer where I click cells to place notes and build a loop bar by bar, with that crunchy NES / Game Boy voice on everything.

Give me a proper rack of instruments to stack into a track — a square-wave lead, a pulse/triangle bass, chiptune drums (kick, snare, hat), an arpeggiator, maybe a noise channel and a couple more — each its own little pixel-synth voice with its own row in the sequencer so I can layer them into a beat. Let me pick the pitch per cell (a small piano-roll or note selector is great), tune the tempo, and mute / solo and set the volume of each instrument. The point is I can actually compose a catchy little loop, not just trigger one sound.

Make it loop cleanly and feel alive: a playhead sweeping across the grid, cells and instruments lighting up as they fire, a BPM control, and ideally a couple of patterns I can chain into a longer sequence. Wrap it all in a chunky pixel-art UI — think an old tracker or a Game Boy music tool — that's genuinely fun to mess with. One runnable HTML file, everything synthesized in code.
```
