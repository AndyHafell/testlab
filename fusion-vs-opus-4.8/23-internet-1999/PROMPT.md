# The internet in 1999 (v2 — boot to browser)

The exact one-shot prompt, fired at both `openrouter/fusion` and `anthropic/claude-opus-4.8` — same prompt, no follow-ups, no retries:

```
Build a playable version of the internet in 1999 — one runnable HTML file that drops me straight into the era. It should boot like the real thing: a dial-up connection screen, the modem handshake screech, "connecting at 56k," then I'm in a period browser with proper chrome — back / forward / stop / home buttons, an address bar, and a status bar that shows a loading progress and "Document: Done," that whole Netscape/Internet Explorer vibe. Make it feel like firing up a beige box and getting online in '99.

From there I want a real web to get lost in: a homepage portal with a hand-sorted directory of categories (like an old Yahoo or AltaVista) and a search box, linking out to a dozen-plus interlinked GeoCities-style pages — personal fan sites, a band shrine, a conspiracy corner, a pixel-art homepage, the works. Pile on the authentic jank: visitor hit counters ticking up, signable guestbooks, under-construction GIFs, webrings stitching the sites together, marquee and blinking text, tiled background images, garish colors and Comic Sans, those little 88x31 buttons, "best viewed in Netscape." Each page can have its own looping MIDI with a toggle to kill it.

Make the key stuff actually work, not just decoration: the search engine returns only era-appropriate results that link to the real in-world pages, the guestbooks let me sign and remember it for the session, and the counters and webrings actually navigate. Throw in a couple of extras to nail the feeling — a fake Hotmail-style inbox or an AIM/IRC chat window buzzing in the corner. The goal is a dozen-plus real, clickable pages that genuinely feel like surfing in 1999, and I can wander a while without hitting a dead end. One runnable HTML file.
```
